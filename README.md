# SRL Hand UI


## Setup

```powershell
npm install
npm start
```

## Controls

- Connect Serial: opens the serial port using Web Serial.
- Reset View: resets the camera.
- Clear Log: clears the last message and console.
- Left mouse drag: orbit.
- Scroll wheel: zoom.
- Right mouse drag: pan.
- L key: log camera position.
- R key: reset camera.
